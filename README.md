# Vijay P - Portfolio

Single-file static site (`index.html`). React 18.3.1 loads from cdnjs, so an internet connection is needed for the interactive sections.

## Run locally
Open `index.html` in a browser, or run `python3 -m http.server` in this folder.

## Deploy free
- GitHub Pages: push to a repo named `<username>.github.io`, then enable Pages.
- Netlify or Cloudflare Pages: drag and drop this folder.

## Edit
- Project and skill data are in the `<script>` at the bottom (`PJ` and `SK` arrays).
- Replace the GitHub links with each project's repo URL.
